# Exportar as configs

## Exportar o plano

1. Na barra superior, clique em `Exportar`.
2. O plano de exportacao (JSON) e copiado para a area de transferencia.

## Revisar o JSON

Abra a aba `JSON` do BottomPanel para inspecionar, derivados via `engine/slotConfigExport`:

- `Export plan`
- `game.config`
- `theme.config`
- `paytable.config`
- slot draft

## Conferir validacoes

Abra a aba `Erros` do BottomPanel. Ela mostra as validacoes reais do projeto:

- `gameId`
- simbolos
- paylines
- payouts

Resolva os erros antes de exportar para producao.

## Saida

A aba `Saida` do BottomPanel mostra as mensagens de operacao do editor.
